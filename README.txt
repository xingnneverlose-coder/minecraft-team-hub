LoRd_Assasin Team Hub website files

Files:
- index.html: website content and team member details
- style.css: black/red responsive esports styling
- script.js: mobile navigation and copyable recruitment application

How to update your Vercel website:
1. Open your GitHub repository: xingnneverlose-coder/minecraft-team-hub
2. Upload/replace index.html, style.css, and script.js in the repository root.
3. Commit the changes to the main branch.
4. Vercel should redeploy automatically. Refresh your public website.

Important: this is a static website. The form prepares a copyable application but does NOT send or store applications online. To receive applications automatically, connect a form service or backend.
Edit the member names and roles directly in index.html.
